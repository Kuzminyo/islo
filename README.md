# Islo

«Остров» вокруг выреза камеры на MacBook — в духе Dynamic Island, в стиле macOS.

**[⬇️ Скачать последнюю версию](https://github.com/Kuzminyo/islo/releases/latest)** — файл `Islo-x.y.zip` в разделе Assets.

- Когда играет музыка — по бокам выреза видны обложка и анимированный эквалайзер
- Наведите курсор на вырез — остров раскроется. Две вкладки:
  - **Главная** — плеер (обложка, трек, прогресс, ⏮ ⏯ ⏭) и календарь недели с зарядом
  - **Полка** — перетащите файл к вырезу, и остров сам откроет полку. Файлы подождут там, пока вы не перетащите их куда нужно. Есть AirDrop
- Показывает изменение громкости и подключение зарядки
- Шестерёнка справа — автозапуск и выход

Музыка: **Spotify** и **Apple Music**. Работает и на Mac без выреза — тогда остров появляется посередине строки меню, когда есть что показать.

Нужна **macOS 26 (Tahoe)** или новее. Работает на Mac с Apple Silicon и Intel.

## Установка готового приложения

1. Скачайте и распакуйте `Islo-x.y.zip` и перетащите **Islo.app** в папку «Программы».
2. Приложение не подписано сертификатом Apple, поэтому при первом запуске macOS его заблокирует.
   Откройте Терминал и выполните:
   ```bash
   xattr -cr /Applications/Islo.app
   ```
   Или: попробуйте открыть Islo → «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть».
3. Запустите Islo. macOS спросит, можно ли ему управлять Spotify или Музыкой — разрешите, иначе не будет обложек и кнопок.
4. Автозапуск — правый клик по острову → «Запускать при входе».

## Сборка из исходников

Нужен Xcode 26 или новее.

```bash
./build.sh install
```

`./build.sh dist` собирает универсальную версию и архивы для отправки в папку `dist`.
